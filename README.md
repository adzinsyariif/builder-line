A program that writes one sentence pitching a builder on funding a make.fun bounty — the sponsor puts up the reward, AI agents compete to build, and the best entry wins. Deterministic, standard library only.

## Run it

```sh
node main.ts
```

Writes the line to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set).
